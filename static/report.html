Overview

What this tool does

SeePlaces Tools replaces a manual weekly process — previously requiring an operator to log into the SeePlaces portal, download a report, manually split bookings by guide, calculate totals in Excel, and distribute results — with a single-click automated workflow.

The application connects directly to the SeePlaces API, downloads the booking report for any date range, automatically assigns each booking to the correct guide based on the hotel name, generates a professionally formatted Excel report (split by guide, by region, and with a summary sheet), and provides a live analytics dashboard tracking performance over time.

A second module handles financial reconciliation: comparing the SeePlaces confirmed bookings against the internal system records to detect missing entries, extra entries, and price discrepancies — with a colour-coded Excel output highlighting every issue.

Features

Core capabilities


Automated report download

Logs into SeePlaces automatically using saved credentials, downloads the booking report for any date range, no manual browser interaction needed.

Intelligent guide assignment

Each hotel is mapped to a guide (Kasha, Aneta, or Joanna). The mapping is editable from the UI at any time — no code changes required.

Multi-sheet Excel output

The generated report has three sheets: a Summary KPI overview, the full Guide Report (coloured by guide with totals), and a By Region breakdown.

Financial reconciliation

Compares SeePlaces confirmed bookings with the internal system by booking ID + voucher number. Detects missing entries, extra entries, and price mismatches.

Analytics dashboard

Tracks every guide report run in a local database. Shows trend charts (bookings and revenue per guide), week-over-week deltas, and regional breakdowns.

WhatsApp-ready summary

One-click copy button generates a formatted summary text (bookings + revenue per guide, totals) ready to paste directly into a WhatsApp group.

User Interface

Application tabs


1

Download Report

Full manual control over the download. Enter credentials, select date range, sales channel (all/online/offline), and optionally filter by specific guide. The downloaded file is automatically made available in the Guide Report and Reconcile tabs without needing to re-upload it.

2

Guide Report

The primary weekly workflow tab. Just select the excursion date range — the system handles everything else. Shows a live progress feed while running, then displays a summary card (bookings + revenue per guide) and a download button for the Excel file.

  • Colour-coded guide banners (Kasha = indigo, Aneta = cyan, Joanna = green)
  • Booking rows with alternating backgrounds
  • Yellow highlighted total row per guide
  • By Region sheet: groups bookings by Hammamet, Nabeul, Sousse, Port El Kantaoui, Mahdia, Monastir
  • Summary sheet: KPI overview with guide and region breakdown
  • One-click copy of WhatsApp-formatted summary text
3

Reconcile

Drag-and-drop two files — the SeePlaces report and the internal system report — to run a full reconciliation. The output Excel has four sheets: a colour-coded Summary, Missing in System (red), Extra in System (orange), and Price Mismatches (yellow).

  • Matching key: Booking ID + Voucher Number
  • Price comparison rounded to 2 decimal places
  • Summary stats shown immediately after completion
4

Hotels

Management interface for both login credentials and the hotel-to-guide mapping. Credentials are saved locally and used automatically in the Guide Report tab. The hotel mapping table supports inline guide reassignment (click the coloured pill buttons to switch a hotel between guides), hotel search, adding new hotels, and removing hotels.

  • Changes take effect immediately for future reports (no restart needed)
  • Per-guide hotel count shown in the header
  • Mapping persisted to hotel_mapping.json on disk
5

Analytics

Historical dashboard powered by a local SQLite database. Every guide report run is automatically saved. The dashboard shows:

  • KPI cards: total runs, total bookings tracked, last run count and revenue
  • Per-guide comparison vs previous run (▲/▼ delta indicators)
  • Line chart: bookings per guide trend over all runs
  • Stacked bar chart: revenue per guide trend over all runs
  • Doughnut chart: booking distribution by guide (last run)
  • Horizontal bar chart: bookings by region (last run)
  • Cancelled booking count alert

Security & Privacy

Data handling

All data remains on the local machine. There are no external cloud services, no data uploads to third-party servers, and no analytics tracking. The application operates entirely offline except for the authenticated connection to the SeePlaces API for downloading reports.

  • Credentials stored in settings.json on the local disk only
  • Hotel mapping in hotel_mapping.json on the local disk only
  • Analytics history in history.db SQLite file on the local disk only
  • Downloaded reports saved to uploads/ and outputs/ folders
  • Flask server listens only on localhost:5174 — not accessible from the network
